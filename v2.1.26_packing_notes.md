### Issue 4: West Malaysia shipping calculation error
- **Problem**: calculateNormalShippingFee (db.ts:7570) has correct logic:
  - subtotal >= 150: first 10kg free, excess RM3/kg
  - subtotal < 150: RM15 for first 10kg, excess RM3/kg
- **BUT**: processActualWeight (db.ts:7711) has `needsSpecialOrder = Math.abs(difference) > 0.01 && actualWeightKg > 10`
  - This means special order only triggers if weight > 10kg, which is wrong
  - Should trigger whenever there's a difference
- **User example**: 12kg with free shipping → should charge 2kg × RM3 = RM6
  - Current logic: calculateNormalShippingFee(itemsSubtotal, 12) → if free shipping: excessWeight=2, shippingFee=2*3=6 ✓
  - But needsSpecialOrder won't trigger if actualWeightKg <= 10... wait 12 > 10 so it would trigger
  - Actually the issue is: if customer paid shippingFee (e.g. RM15 for <150 subtotal) and actual is also RM15+6=21 for 12kg, difference = 6, needsSpecialOrder = true (12 > 10) ✓
  - If free shipping (>=150) and actual weight 12kg: shippingFee = 6, customerPaidShipping = 0, difference = 6, needsSpecialOrder = true ✓
  - If free shipping and actual weight 8kg: shippingFee = 0, customerPaidShipping = 0, difference = 0, needsSpecialOrder = false ✓
  - If NOT free shipping and actual weight 8kg: shippingFee = 15, customerPaidShipping = 15, difference = 0, needsSpecialOrder = false ✓
  - The condition `actualWeightKg > 10` seems to prevent triggering when weight <= 10 but there's still a difference
  - Example: subtotal < 150, customer paid RM15, actual weight 5kg → shippingFee = 15, difference = 0 → OK
  - Example: subtotal >= 150, customer paid RM0, actual weight 5kg → shippingFee = 0, difference = 0 → OK
  - The `actualWeightKg > 10` condition seems fine for most cases but could miss edge cases where weight < 10 but difference exists
  - Actually: if subtotal < 150 and weight = 5kg: fee = 15, paid = 15, diff = 0 → OK
  - If subtotal >= 150 and weight = 5kg: fee = 0, paid = 0, diff = 0 → OK
  - So the only way to have a difference with weight <= 10 is if customerPaidShipping doesn't match the calculated fee
  - This could happen if the order was created with wrong shipping fee
  - **Fix**: Remove the `actualWeightKg > 10` condition, just use `Math.abs(difference) > 0.01`
