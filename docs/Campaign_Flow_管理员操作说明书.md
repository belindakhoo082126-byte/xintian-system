# 心田系统 Campaign Flow 管理员操作说明书

> **适用对象：** 心田系统管理员。  
> **适用模块：** 后台的「Marketing Center／Campaign Flow」。  
> **用途：** 将同一推广主题的 Facebook Post、Reel 或 Video 集中管理，并配置客户互动后的自动回复、Messenger 流程、商品按钮与订单统计。

## 一、Campaign Flow 是什么

一个 **Campaign（营销活动）** 代表一个完整的推广主题，例如「八月室内植物优惠」、「中秋礼盒预购」或「新到肥料介绍」。同一 Campaign 可以绑定多个 Facebook 内容，并共用同一套自动回复、流程步骤、商品按钮及统计资料。

当客户在已绑定的 Facebook 内容互动时，系统会依照该 Campaign 的状态及已绑定商品范围处理。营销活动只会匹配该活动内已配置的商品，不会自动拿全店商品来捉单，因此可降低不同贴文之间误捉商品的风险。

| 项目 | 用途 |
|---|---|
| Campaign | 一个推广主题的总容器，例如「母亲节花礼」 |
| 内容 ID | 与该 Campaign 关联的 Facebook Post、Reel 或 Video |
| Flow | 已配置的消息步骤与先后顺序 |
| 商品按钮 | 本活动允许匹配的指定商品及默认数量 |
| 状态 | 草稿、启用、结束、封存 |
| 统计 | 关联内容数、自动订单数、合单数、商品数量与营业额 |

## 二、开始前的准备

在建立 Campaign 前，请先准备 Facebook 内容链接、推广名称、自动回复文案，以及需要销售的商品。商品必须已在「商品管理」中建立完成，并确认名称、规格、关键词、库存及售价正确。

若活动要用留言关键词捉单，请先确认商品本身已有可识别的关键词。Campaign 只会从本活动已绑定的商品中匹配关键词；即使全店存在同名或相近商品，也不会被本活动自动带入。

| 准备项目 | 建议做法 |
|---|---|
| 活动名称 | 使用容易辨认的格式，例如「2026-08 室内植物 Reel 促销」 |
| Facebook 链接 | 复制完整的 Post、Reel 或 Video 链接 |
| 商品 | 先核对关键词、规格、现货／预售设定与售价 |
| 文案 | 准备公开自动回复与私讯流程文字 |
| 图片／视频 | 准备可公开访问的媒体 URL；目前 Flow 的媒体步骤以 URL 方式填写 |

## 三、建立一个新的 Campaign

进入后台 **Marketing Center → Campaign Flow**，点击右上角的「建立 Campaign」。在「设置」分页填写活动名称，这是唯一必填的基础资料。建议先以「草稿」建立并保存，再继续后续设置。

保存后，系统才会开放「内容 ID」「流程」及「按钮」三个分页。这个顺序是必要的，因为后续资料都必须关联到已产生的 Campaign 编号。

### 3.1 设置分页

在设置分页中，可调整公开自动回复、自动回复文字与 Messenger Flow 开关。建议在测试阶段先保留为草稿，并填写不会造成误导的测试文案；正式内容确认后再切换为启用。

| 字段／开关 | 应如何填写 |
|---|---|
| 活动名称 | 填写管理员一看就能识别的推广主题 |
| 自动回复 | 需要时开启，并填写客户留言后可看到的简短回应 |
| 自动回复文字 | 说明下一步，例如「谢谢留言，我们已私讯商品资料给您。」 |
| Messenger Flow | 需要发送活动私讯流程时开启 |

## 四、绑定 Facebook 内容

打开「内容 ID」分页，将完整 Facebook 链接贴入输入框后点击「加入」。系统会识别内容类型与内容 ID；一个 Campaign 可以绑定多条 Post、Reel 或 Video，所有已绑定内容会共用本活动的设置及统计。

绑定后应在列表确认内容类型、内容 ID 和「打开链接」是否正确。若贴错内容，可在同一列点击删除；删除绑定不会删除 Facebook 原帖，只会解除本系统的关联。

> **建议：** 同一支推广贴文不要同时绑定到两个启用中的 Campaign，以免管理员无法清楚判断应该由哪一套商品范围及流程处理。

## 五、设置客户消息 Flow

打开「流程」分页，点击「新增步骤」后选择内容类型，并按希望的客户阅读顺序建立。每个步骤可用上／下箭头调整位置；系统会按此顺序保存步骤，正式上线前必须以测试内容实际确认客户端的发送效果。

当前前端可新增的步骤类型包括文字、图片、视频、商品介绍和按钮。图片及视频步骤填写可公开读取的 URL；请在正式启用前先确认链接可在未登录状态打开。

| 步骤类型 | 推荐内容 | 使用提示 |
|---|---|---|
| 文字 | 欢迎语、活动规则、关键词提示、付款说明 | 尽量短句分段，先说明客户下一步要做什么 |
| 图片 | 商品合集图、优惠图、尺寸说明图 | 填入公开图片 URL，避免使用后台本机路径 |
| 视频 | 植物实拍、使用说明、促销短片 | 填入公开视频 URL，并先测试手机播放 |
| 商品介绍 | 商品卖点、尺寸、照顾重点、价格说明 | 建议一项商品介绍配合一个清晰关键词 |
| 按钮 | 引导客户选择指定商品或进入下一步 | 商品实际绑定在「按钮」分页完成 |

目前 Campaign Flow 的可视化新增界面没有独立的「语音／音频」选项。请不要把音频 URL 当作图片或视频步骤使用；如需在 Campaign 中加入语音，需要另行扩充前端操作入口后再使用。

## 六、设置商品按钮与捉单范围

打开「按钮」分页，点击「新增按钮」。依次填写名称、选择对应商品，并填写默认数量。保存后，按钮会显示商品名称、SKU／关键词及数量；它同时定义本 Campaign 可匹配的商品范围。

每个按钮都有独立启用开关。关闭某个按钮后，该商品会保留在设置记录中，但不应作为本次活动的有效商品入口；重新开启即可恢复使用。删除按钮会移除该活动与商品的绑定，不会删除商品本身。

| 设置项目 | 正确做法 |
|---|---|
| 按钮名称 | 使用团队容易辨认的名称，例如「我要 1 包有机肥」 |
| 绑定商品 | 选择已建立并核对库存／售价的正确商品 |
| 数量 | 填写每次点击默认加入的数量，通常为 1 |
| 启用开关 | 正式活动期间开启；停售、缺货或暂时不推广时关闭 |

> **关键规则：** Campaign 的 Facebook 留言捉单只会匹配此 Campaign 已绑定到按钮的商品。若客户留言无法成立订单，请先检查 Campaign 是否启用、Facebook 内容是否已绑定、按钮是否开启，以及商品关键词是否正确。

## 七、测试与正式启用

当前 Campaign Flow 页面没有独立的「发送测试消息」或「预览全部流程」按钮。因此最安全的测试方式是使用测试用 Facebook 内容、测试客户账号及可撤销的测试订单，避免直接在正式贴文上试验。特别是 Flow、公开自动回复与 Messenger Flow 开关虽可在后台配置，仍应以测试互动确认实际客户端收到的内容。

建议按以下顺序测试。首先建立草稿 Campaign 并绑定一条测试内容，再加入一项测试商品及按钮。接着以测试账号在该内容留言符合商品关键词的文字，或按活动设计执行商品选择动作。最后检查系统是否正确识别活动来源、建立／合并正确订单、保留正确商品数量，并能从客户结账入口查看订单。

| 测试项目 | 应确认的结果 |
|---|---|
| 贴文绑定 | 测试内容出现在 Campaign 的内容 ID 列表 |
| 商品范围 | 只有本 Campaign 已绑定的商品可以被匹配 |
| 数量与价格 | 订单商品、规格、数量和成交价均正确 |
| 库存 | 成功订单后，库存预留及商品数量阶段正常同步 |
| 订单来源 | 订单可辨认为此 Campaign／Facebook Post 来源 |
| 客户入口 | 客户能收到或访问对应订单的结账入口 |

测试完成后，请删除或取消测试订单，避免测试数据混入实际营业额及库存记录。确认无误后，在 Campaign 卡片点击「开始」，将状态从「草稿」切换为「启用」。只有**启用**状态的 Campaign 会按 Campaign 规则处理新互动。

## 八、状态管理、复制与统计

Campaign 卡片会显示当前状态、绑定内容数、自动订单数、合单数、商品数量与营业额。活动完成后应点击「结束」，停止新的自动流程但保留历史资料；不再需要日常查看的历史活动可「封存」。

| 状态 | 适用情境 | 对新互动的处理 |
|---|---|---|
| 草稿 | 正在编写、测试或等待发布 | 不按正式 Campaign 自动流程处理 |
| 启用 | 正式推广期间 | 按已绑定内容、流程及商品范围处理 |
| 结束 | 促销结束，需要保留报表 | 停止新自动流程，保留历史资料 |
| 封存 | 长期不用的旧活动 | 停止新自动流程；需要时可恢复再用 |

若要复用旧活动，可点击「复制」。新副本会以草稿状态建立，适合用来更换文案、商品或新的 Facebook 内容后再次测试；复制后请重新核对所有设置，不要直接启用。

## 九、日常操作建议

建立活动时，建议每个 Facebook 内容主题只绑定必要商品，不要把全店商品全部加入。这样客户留言「肥料」或「花盆」等通用字词时，较不容易误匹配。活动上线后，应每天查看卡片统计及相关订单，确认商品数量、特价、库存和付款状态都符合预期。

活动文案应清楚写明客户如何操作，例如「留言关键字：MON」「点击按钮选择数量」或「完成后请到结账页填写配送资料」。若活动涉及特价或运费门槛，也应明确说明特价商品不计入 RM150 免邮基数，避免客户对金额产生误解。

## 十、常见问题排查

| 情况 | 优先检查项目 |
|---|---|
| 新建后看不到内容 ID／流程／按钮分页 | 先填写活动名称并点击保存；保存后分页才会开放 |
| 客户留言后没有按活动捉单 | Campaign 是否为启用、贴文是否已绑定、商品是否有对应关键词、按钮是否已开启 |
| 捉到不应出现的商品 | 检查本活动的按钮绑定与商品关键词；移除不属于本活动的商品按钮 |
| 图片／视频无法显示 | 确认填写的是公开可访问 URL，而非电脑本地路径或受登录保护链接 |
| 需要暂停售卖一项商品 | 关闭该商品按钮，不必删除整个 Campaign |
| 活动结束但想保留报表 | 点击「结束」，不要直接删除 Campaign |
| 想重用过去活动 | 使用「复制」，再逐项更新名称、内容、商品与文案后测试 |

## 十一、建议的标准工作流程

建议团队固定采用以下顺序：**建立草稿 → 保存 → 绑定 Facebook 内容 → 排列 Flow → 绑定商品按钮 → 测试留言／下单 → 核对订单与库存 → 启用 → 每日查看统计 → 结束／封存**。这个流程可以将内容、商品、库存和订单的核对放在正式发布之前，降低错价、错单或误捉单风险。
