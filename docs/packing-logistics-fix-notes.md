# 包货物流与打印修复记录

本批修复聚焦订单区域 8 与包货工作台之间的物流资料一致性。包货详情已展示客户、商品、已建包裹、实际重量、实际运费、发货日期及已保存 AWB；但服务层在完成发货时仅回写订单的快递公司、追踪号码与物理发货状态，未统一回写包裹层的标签链接、重量与实际物流费用。

包货工作台列表与详情页目前各自维护一套 A5 打印模板。后续应以同一份订单资料与同一条备注汇总规则生成模板，确保下单人、收件人、商品、备注与物流资料一致，且不会重复显示备注。

本批不改变已存在的 Parcel Daily 生成、重新获取 AWB 或物流通知流程；仅补齐已保存数据的订单级同步、地址读取与打印口径。
