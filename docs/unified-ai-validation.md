# 统一 AI 客服架构验证记录

## 已验证的自动化链路

本轮通过 TypeScript 编译和 Vitest 回归套件验证以下受控边界：私聊文本由统一编排器进行幂等仲裁；人工接管后不再自动回复；客户语音在低可信度或订单性意图时进入人工复核与文字确认边界；自动跟进策略默认暂停并尊重人工接管、订单唯一投递与投递审计；直播评论及固定 Flow 使用 `public_flow_event_claims` 进行数据库级单次事件占用，重复 webhook 会安全短路，不重复回复或建立订单。

## 界面访问核验边界

客服工作台路由 `/chat` 已可访问且受到既有登录保护。当前验证浏览器没有已登录会话，因此只能看到系统的登录页，未在未授权状态下绕过认证或执行真实发送、建单、扣库存等敏感操作。代码层已确认工作台包含语音播放与修正、AI 销售建议、人工接手与恢复 AI 控件；这些动作仍通过现有受权限保护的接口执行。

## 发布前结论

该架构不改变既有价格、库存、运费或订单服务的计算权。AI 仅可提出建议并记录审计；订单性语音和销售动作必须由客户文字确认或工作人员确认后，才可交给既有业务服务处理。
