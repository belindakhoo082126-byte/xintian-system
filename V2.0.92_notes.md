# V2.0.92 Edit Order Enhancement - Implementation Notes

## Current State
- OrderEditPage.tsx has: basic info, customer info (read-only), recipient/shipping, items (READ-ONLY), amount details (editable), payment records, remarks
- Missing: order status edit, item edit (add/remove/update qty/price/variation), timeline logging for item changes
- Backend: `updateOrderDetails` in db.ts only updates order-level fields, no item support
- Backend: `updateDetails` procedure in routers.ts passes through to updateOrderDetails
- `searchProductsForOrder` procedure already exists - can be reused for "add product"
- `calculateWestMalaysiaShipping` is used in createOrderWithSplit for shipping recalculation
