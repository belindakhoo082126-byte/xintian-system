# V2.1.17 Investigation Notes - Customer Search & Address Auto-fill

## User Requirements (from pasted_content_11.txt)
1. Customer search in OrderCreatePage/OrderEditPage should search from main customers table
2. Phone number normalize (strip spaces, dashes, +60 prefix)
3. Selecting customer auto-fills complete recipient address
4. Save Receiver Snapshot (recipientName, recipientPhone, shippingAddress, etc.)
5. Local and XTC orders use same search logic
6. Customer search results show address summary + Credit balance

## Current State

### customers table schema (drizzle/schema.ts)
- Has: id, name, phone, facebookName, facebookId, creditBalance, blacklist, notes, createdAt
- Does NOT have: address, state, city, postcode, shippingAddress fields
- **Problem**: No address fields in customers table!

### orders table has recipient fields:
- recipientName, recipientPhone, shippingAddress, shippingState, shippingCity, shippingPostcode, shippingArea

### OrderCreatePage.tsx
- Has customer search via trpc.customers.list.useQuery with searchQuery
- handleCustomerSelect sets customerId but does NOT auto-fill recipient fields
- recipientForm state has: recipientName, recipientPhone, shippingAddress, shippingState, shippingCity, shippingPostcode, shippingArea
- Customer search results show name, phone, facebookName but NOT address

### OrderEditPage.tsx
- Has customer selection but similar issue - doesn't auto-fill recipient from customer

### getCustomers in db.ts
- Searches by name, phone, facebookName with LIKE
- Returns: id, name, phone, facebookName, facebookId, creditBalance, blacklist, notes, createdAt
- Does NOT return address (because customers table has no address fields)

### getCustomerById in db.ts
- Returns same fields as getCustomers

## What needs to be done:
1. Add address fields to customers table: address, state, city, postcode, area
2. Create unified searchCustomer function with phone normalize
3. Create getCustomerDefaultAddress function
4. Update OrderCreatePage/OrderEditPage to auto-fill recipient fields when customer selected
5. When order is created, save customer's address back to customer profile (if empty)
6. Show address summary + Credit in search results
