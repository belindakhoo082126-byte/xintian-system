# V2.1.20 Investigation: Customer Address Sync Issues

## Root Causes Identified

### 1. Orders.tsx (old create order entry)
- Customer select (2132-2152): Fills structured fields into recipientForm ✓
- Create order payload (294, 563): Only passes `shippingAddress: customerForm.address`, **missing structured address fields**
- UI (2204-2205): Only shows textarea for `customerForm.address`, no structured address inputs for recipient

### 2. OrderEditPage.tsx
- Customer select (556-563): Only fills `recipientName`, `recipientPhone`, `shippingAddress` - **no structured address**
- formData (63-79): Only has `shippingAddress` (flat), **no recipientCity/State/Postcode/Country**
- updateOrderDetails (db.ts 1118-1177): **Doesn't accept** recipientCity/State/Postcode/Country
- routers.ts updateDetails (1196-1217): **No structured address fields** in input schema

### 3. Customers.tsx
- Detail view (526-529): Only shows `detailCustomer.address` (flat)
- New customer dialog (1163-1185): Only has `address` input, **no city/state/postcode/country**
- newCustomer state: Only has `address` field

### 4. Backend - findOrCreateCustomer (db.ts 277-333)
- Only accepts `address` (flat), **doesn't accept** city/state/postalCode/country

### 5. Backend - createOrderWithSplit address sync (db.ts 1006-1030)
- Syncs address to customer only if empty ✓
- But concatenates addressLine1+addressLine2 into `address` field - could cause duplication

### 6. OrderCreatePage.tsx (mostly fixed in V2.1.17)
- handleCustomerSelect (326-355): Uses search result directly (already returns all fields) ✓
- Create order mutation (227-244): Already passes structured address fields ✓

## Fix Plan

### Backend:
1. updateOrderDetails + routers.ts: Add recipientCity/State/Postcode/Country
2. findOrCreateCustomer + routers.ts: Add city/state/postalCode/country params
3. createOrderWithSplit: Fix address sync to not concatenate

### Frontend:
1. Orders.tsx: Pass structured address fields to create order
2. OrderEditPage.tsx: Add structured address to formData, customer select, UI, and save
3. Customers.tsx: Show structured address in detail, add structured fields in new customer dialog
