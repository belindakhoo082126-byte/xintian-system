# V2.1.26 Packing Workstation Fixes - Implementation Notes

## Issues to Fix (11 items)

### Issue 1: Shipping fee not shown in packing workstation
- **Problem**: getPackingOrders doesn't return shippingFee, customerPaidShipping, physicalSubtotal
- **Fix**: Add these fields to the select in getPackingOrders (db.ts line ~5689)

### Issue 3: Show "免邮" (Free Shipping) label next to actual weight/shipping
- **Problem**: No indication when order has free shipping (subtotal >= RM150)
- **Fix**: In PackingDetail.tsx actual weight card, show "免邮" badge when customerPaidShipping is 0 and order qualifies for free shipping
- Also show how much customer should pay based on actual weight

### Issue 4: West Malaysia shipping calculation error
- **Problem**: processActualWeight has `needsSpecialOrder = Math.abs(difference) > 0.01 && actualWeightKg > 10`
  - This means orders under 10kg with a difference DON'T trigger special order
  - Also, the calculation seems correct per V2.2 rules but display may be wrong
- **V2.2 Rules**: 
  - subtotal >= RM150: first 10kg free, excess RM3/kg
  - subtotal < RM150: first 10kg RM15, excess RM3/kg
- **Fix**: Remove the `actualWeightKg > 10` condition from needsSpecialOrder check
  - Any difference > 0.01 should trigger special order

### Issue 5: Exception handling cannot save
- **Problem**: createExceptionMutation onSuccess doesn't invalidate packing detail
- **Fix**: Add `utils.packing.detail.invalidate({ orderId })` in createExceptionMutation onSuccess

### Issue 6: A5 print button overlaps with language toggle
- **Problem**: A5 print button is in the header next to language toggle
- **Fix**: Move A5 print button to be next to order number, and ensure print CSS has proper print-hide/print-only classes

### Issue 7: Add print button next to each order's packing button in packing list
- **Problem**: No per-order print button in Packing.tsx list
- **Fix**: Add a Printer icon button next to "包货" button for each order in the list

### Issue 8: Batch print checkboxes in packing list
- **Problem**: No way to select multiple orders for batch printing
- **Fix**: Add checkboxes to each order card, and a "batch print" button

### Issue 9: Simplified print format
- **Requirements**: 
  - No images
  - Order number (large)
  - Product list (large quantity, 2+ grid cells)
  - Order total
  - Product keywords
  - Unit price and subtotal
  - Large display: 西马, 东马 shopee, 东马 poslaju, lalamove
- **Fix**: Rewrite A5PackingSlip component

### Issue 11: Ensure local AND import orders sync to packing workstation
- **Problem**: getPackingOrders only queries `physicalStatus`, missing import orders with `importStatus = ready_to_ship`
- **Fix**: Modify getPackingOrders to also query import orders
  - For local orders: physicalStatus = "packing" etc
  - For import orders: importStatus = "ready_to_ship" etc
  - Need to check orderCategory to determine which status field to use
